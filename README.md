# Walmart Sales Analysis
## Project Overview
This project analyzes Walmart sales data using Python. The goal is to understand sales patterns, compare store performance, and compare store performance, and generate business insights through data analysis and visualization.
## Tools Used
- Python
- Pandas
- Matplotlib
- Goggle Colab
## Dataset
- Walmart Sales Dataset
- 6,435 records
- 8 columns
## Analysis Performed
- Data exploration
- Missing value analysis
- Mean, Median, and Mode calculation
- Descriptive Statistics
- Store-wise sales analysis
- Holiday vs Non-Holiday sales comparison
- Top 10 stores by total sales
- Monthly sales trend analysis
## Visualization
- Bar chart
- Line chart
- Histogram
- Box plot
## Business Insights
- Holiday weeks generated higher average sales than non-holiday weeks.
- Store 20 achieved the highest total sales.
- Sales varied across stores, indicating differences in customer demand.
- Weekly sales contained several high-value outliers.
- Monthly sales fluctuated over time, showing seasonal trends.
